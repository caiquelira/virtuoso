MIDI Check

Checks that your keyboard reaches the computer, which channels it uses, and how finely it measures how hard you play. That last part decides whether the game can grade voicing.

1. Set up the keyboard

  1. Connect the keyboard's USB TO HOST port to the PC with a USB 2.0 A-to-B cable shorter than 3 m. No driver is needed.
  2. Press PORTABLE GRAND. It resets to plain piano and turns Dual and Split off.
  3. Press FUNCTION until 008 TouchRes shows, then choose 2 (Medium) or 3 (Hard). Not 4 (Fixed), which plays every note at the same loudness.
